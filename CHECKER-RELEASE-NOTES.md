## Что изменилось

- Во вкладке «Mihomo / OpenClash» появилась отдельная кнопка «Диагностика Mihomo» и неблокирующее окно с прогрессом и подробными результатами.
- Диагностика запускает временный изолированный Mihomo на свободных локальных портах и проверяет бинарник, конфигурацию, запуск, контроллер, авторизацию и ключевые API-методы.
- Пять контрольных HTTPS-сайтов проверяются тремя независимыми путями: напрямую, через API URL-test и через локальный HTTP-прокси с маршрутом DIRECT.
- DNS-, TLS-, proxy-, API-ошибки и тайм-ауты показываются отдельно; ответы URL-test HTTP 503/504 не объявляют весь контроллер неисправным.
- Отчёт можно скопировать или сохранить в TXT/JSON. Секрет API и чувствительные значения автоматически исключаются из отчёта.
- Временный процесс и конфигурация гарантированно удаляются после завершения, ошибки или закрытия окна.
