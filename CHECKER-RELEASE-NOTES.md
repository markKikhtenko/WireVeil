## Что изменилось

- Локальный сервер роутерной подписки теперь автоматически восстанавливается после перезапуска WireVeil Checker, если раньше был включён. Стабильный URL снова доступен роутеру без повторной сборки.
- Ручная кнопка «Остановить сервер» запоминает выбор и не запускает сервер самовольно при следующем старте.
- URL подписки отвечает как обычный UTF-8 текст, поэтому браузер показывает YAML вместо принудительного скачивания файла.
- Добавлена поддержка HTTP `HEAD` для загрузчиков подписок Mihomo/OpenClash.

### Надёжность обновления

- Загрузка обновления автоматически повторяется до трёх раз, если соединение оборвалось или полученный пакет не совпал с опубликованной контрольной суммой.
- Неполная загрузка теперь определяется отдельно по `Content-Length`; частичный файл удаляется перед новой попыткой.
- Проверка SHA-256 остаётся обязательной: приложение никогда не запускает пакет, пока его контрольная сумма не совпадёт с опубликованной.
