## Что изменилось

- Вкладка «Сборка для роутера» больше не проверяет доступность серверов и не отбрасывает их по HTTPS-прогонам. Она скачивает выбранные источники, объединяет узлы и сразу собирает YAML.
- Обычные подписки со ссылками `vless://`, `trojan://`, `ss://`, `vmess://`, `hysteria2://` и `tuic://` теперь преобразуются в Mihomo-конфигурацию. Поддерживаются обычный TXT, Base64 и готовый Clash/Mihomo YAML.
- Одинаковые конфигурации удаляются, а локальная проверка Mihomo оставляет только синтаксически совместимые записи. Сетевых запросов через прокси при сборке нет.
- Группы `GLOBAL`, `AUTO` и `ALL` сохраняются. Доступность серверов определяет `AUTO` уже непосредственно на роутере.
- Убраны ненужные настройки количества HTTPS-прогонов, тайм-аута и параллельности из вкладки сборки.
- Ошибка «Нет полностью рабочих узлов» больше не появляется из-за недоступности тестовых HTTPS-адресов.

### Надёжность обновления

- Загрузка обновления автоматически повторяется до трёх раз, если соединение оборвалось или полученный пакет не совпал с опубликованной контрольной суммой.
- Неполная загрузка теперь определяется отдельно по `Content-Length`; частичный файл удаляется перед новой попыткой.
- Проверка SHA-256 остаётся обязательной: приложение никогда не запускает пакет, пока его контрольная сумма не совпадёт с опубликованной.
