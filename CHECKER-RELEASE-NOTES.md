## Что изменилось

- При переходе на мультиподписку пустое поле ручной вставки теперь скрывается. Вместо него приложение показывает, сколько источников выбрано.
- Большая кнопка полной проверки теперь действительно загружает, объединяет и проверяет отмеченные подписки, если активен режим мультиподписки.
- Кнопки «Вставить», «Выбрать файл…» и «Ручной ввод» явно возвращают обычный режим с полем ввода. Сохранённый список подписок при этом не удаляется.
- Выбранный режим сохраняется для следующего запуска и используется автоматической проверкой.

### Надёжность обновления

- Загрузка обновления автоматически повторяется до трёх раз, если соединение оборвалось или полученный пакет не совпал с опубликованной контрольной суммой.
- Неполная загрузка теперь определяется отдельно по `Content-Length`; частичный файл удаляется перед новой попыткой.
- Проверка SHA-256 остаётся обязательной: приложение никогда не запускает пакет, пока его контрольная сумма не совпадёт с опубликованной.
