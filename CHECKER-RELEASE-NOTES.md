## Что изменилось

- YAML из вкладки «Сборка для роутера» теперь использует группы `AUTO`, `MANUAL` и `PROXY` — как `subscription-lan-experimental.yaml` в pale-signal.
- `AUTO` автоматически проверяет все серверы, `MANUAL` позволяет выбрать сервер вручную, а главная группа `PROXY` переключается между ними и по умолчанию использует `AUTO`.
- Группы `GLOBAL` и `ALL` удалены. `DIRECT` остаётся встроенным выходом Mihomo, а финальное правило изменено на `MATCH,PROXY`.
- Существующий оверрайт OpenClash менять не требуется.

### Надёжность обновления

- Загрузка обновления автоматически повторяется до трёх раз, если соединение оборвалось или полученный пакет не совпал с опубликованной контрольной суммой.
- Неполная загрузка теперь определяется отдельно по `Content-Length`; частичный файл удаляется перед новой попыткой.
- Проверка SHA-256 остаётся обязательной: приложение никогда не запускает пакет, пока его контрольная сумма не совпадёт с опубликованной.
