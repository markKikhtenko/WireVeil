## Что изменилось

- Добавлена третья вкладка «Сборка для роутера»: Checker загружает выбранные Mihomo/Clash-подписки, проверяет узлы и собирает локальный YAML только из полностью рабочих серверов.
- Готовую подписку можно сохранить в файл или отдать роутеру по защищённому локальному HTTP-URL, который работает, пока Checker запущен.
- В конфигурацию роутера входят готовые группы `GLOBAL`, `AUTO` и `ALL`, правила прямого доступа к локальной сети и финальное правило `MATCH,GLOBAL`.
- Умный рейтинг обычной проверки теперь учитывает одновременно скорость и задержку: небольшая прибавка скорости больше не поднимает наверх сервер с гораздо худшим ping.
- В окне списка обычных подписок появилась кнопка «Скачать TXT». Она сохраняет URL по одному на строку для переноса на другой компьютер; такой TXT можно загрузить обратно через «Добавить файлы…».
- TXT содержит приватные URL подписок, поэтому Checker явно предупреждает, что файл нельзя публиковать.

### Надёжность обновления

- Загрузка обновления автоматически повторяется до трёх раз, если соединение оборвалось или полученный пакет не совпал с опубликованной контрольной суммой.
- Неполная загрузка теперь определяется отдельно по `Content-Length`; частичный файл удаляется перед новой попыткой.
- Проверка SHA-256 остаётся обязательной: приложение никогда не запускает пакет, пока его контрольная сумма не совпадёт с опубликованной.
