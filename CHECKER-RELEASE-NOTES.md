## Что изменилось

- Загрузка удалённых источников для роутерной подписки автоматически повторяется до трёх раз при временных сетевых, DNS- и серверных ошибках.
- Проверка безопасности адреса выполняется перед каждой повторной попыткой, поэтому защита от локальных и служебных URL сохраняется.
- Вместо общей ошибки «нет поддерживаемых узлов» приложение показывает причину: источник не загрузился, формат не поддерживается, YAML не разобран либо Mihomo отклонил конфигурацию узлов.
- Неудачная сборка по-прежнему не перезаписывает ранее созданную рабочую подписку.

### Надёжность обновления

- Загрузка обновления автоматически повторяется до трёх раз, если соединение оборвалось или полученный пакет не совпал с опубликованной контрольной суммой.
- Неполная загрузка теперь определяется отдельно по `Content-Length`; частичный файл удаляется перед новой попыткой.
- Проверка SHA-256 остаётся обязательной: приложение никогда не запускает пакет, пока его контрольная сумма не совпадёт с опубликованной.
